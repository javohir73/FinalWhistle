FinalWhistle · Concept 1c "Floodlight" · Implementation plan

From World Cup app to multi-sport platform

Scope: Football space (EPL · LaLiga · Bundesliga · WC26 as subsections) + separate NRL space, in the Floodlight broadcast visual language. Sports are never interleaved in one feed. Stack: existing Next.js App Router + Tailwind frontend; FastAPI + pipeline untouched except serving league metadata.

1 · Information architecture & routes

lib/sports.ts becomes a config registry — routes become templates, not trees
app/
  (football)/football/[comp]/            comp ∈ epl · laliga · bundesliga · wc26
    page.tsx            → Home (Tonight's feature)
    fixtures/           → timeline spine list      ("Fixtures")
    match/[id]/         → match centre
    standings/          → StandingsTable + zones   ("Standings")
    team/[id]/
  (nrl)/nrl/
    page.tsx · matches/ · match/[id]/ · ladder/ · team/[id]/   ("Matches", "Ladder")
  play/                 → cross-competition Play hub (grouped by sport, labelled)
  you/                  → profile, followed teams, saved competitions
  • One SPORTS registry drives nav links, terminology ("fixtures/standings" vs "matches/ladder"), zone configs, and which tabs exist (Bracket only for WC26). Kills today's duplicated /nrl/* parallel tree logic.
  • Competition switcher = full-screen typographic overlay (Floodlight signature). Sports are section-separated; starring pins a competition. Persisted in localStorage + account.
  • Current URLs 301 into the new scheme (/matches → /football/wc26/fixtures, /nrl/ladder → /nrl/ladder).

2 · Design tokens (extends the existing DS — nothing replaced)

Keep as-is
Colors (canvas/surface/win/draw/loss/gold), Bricolage + Hanken, 4px spacing, radii, glass, expo-out easing, atmosphere.
New — display scale
--text-display-hero: 46/74px · -0.03em (feature %, scorebug), --text-rank: 22px (ladder numerals). Min body 13px, nav labels 11px (fixes current 10px WCAG issue).
New — status states
--status-upcoming (muted), --status-live (rose dot + rose/40 ring, 2s pulse), --status-ft (surface-2 chip). Confidence: HIGH=lime, MEDIUM=amber, LOW=muted — ring + label, never colour alone.
New — competition branding
--comp-accent per league (EPL purple, LaLiga coral, BUN red, NRL teal) used ONLY on the switcher overlay + league eyebrow chips at ≤12% opacity. Lime stays the sole action colour. Crest assets served from our own CDN after licensing (mocks currently hotlink PL/api-sports/nrl.com).

4 · Build phases

P1Foundations — SPORTS registry, route scheme + redirects, token additions, config-driven SiteNav/BottomNav/CompetitionOverlay. No visual change yet.
P2Football space — FeatureHero home, TimelineSpine fixtures, StandingsTable, team pages for EPL; LaLiga + Bundesliga ride the same templates (data only). WC26 keeps Groups/Bracket extras.
P3NRL space — restyle existing NRL pages onto the shared templates (ladder zones, margin chips, Origin placeholder). Delete the parallel component set.
P4Match centre — Scorebug + WinProbTimeline (live poll feed exists), "model says" narrative, pick-vs-AI module. This is the shareable screen; OG images re-templated here.
P5Play hub — merge NRL tips + league tips + WC bracket into one Play tab grouped by sport; single leaderboard with per-competition filters; ConfidenceRing picks.
P6Polish — a11y pass (labels on probability bars, 44px targets, reduced-motion), skeletons, PWA icons/splash, store screenshots in Floodlight skin.

5 · Risks & accessibility

  • Density — Floodlight's big type costs rows per screen; TimelineSpine keeps a compact row variant (Terminal-style) behind a display toggle.
  • Logos — official crests/league marks need licensing; ship with typographic ClubBadge fallback (already exists) so nothing breaks.
  • A11y — W/D/L bars get aria-labels + printed %; live pulse respects reduced-motion; amber text only ≥12px bold; nav labels 11px minimum.
  • Perf — hero glow is one radial-gradient (no images); WinProbTimeline is inline SVG from the existing prob-snapshot endpoint.
